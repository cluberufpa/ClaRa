# Intraspecific variation in the bony traits and elemental phenotype of a marine and freshwater fish

[https://doi.org/10.5061/dryad.6m905qg99](https://doi.org/10.5061/dryad.6m905qg99)

## Description of the data and file structure

We collected stickleback from five populations in the Cowichan drainage and measured their morphological characteristics, some bone characteristics, and the phosphorus (P) content of bodies, bones, diet, and wastes. We also measured excretion in a subset of individuals. See our methods for details on how we did this.

### Files and variables

#### File: Cowichan_Data.xlsx

**Description:** This dataset contains data on 246 stickleback from the Cowichan drainage in 2022-2023. We have marked missing values with "NA." There are two tabs. "Dataset" contains all the data detailed below. "Metadata" details the meaning of all variables.
